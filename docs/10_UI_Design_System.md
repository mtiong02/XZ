# 鲜知 UI 设计系统

## 设计方向

- 气质：温暖、克制、可信赖的家庭生活工具。
- 界面优先表达库存、提醒、餐食和健康事实，不使用无业务意义的 AI 图标或装饰性 emoji。
- 小知形象只作为真实语音入口出现，不在其他功能中重复装饰。

## 基础规范

- 主色：`#287A5B`；深色文字：`#17201A`；页面底色：`#FAFAF7`。
- 正文最小 14px，辅助文本最小 12px；中文使用系统字体栈。
- 主要圆角 16px，页面区块 24px；阴影只表达浮层和可点击层级。
- 交互控件高度至少 42px，移动端主要触控目标至少 44px。
- 所有交互必须支持键盘焦点，状态不能只靠颜色表达。

## 响应式规则

- `> 920px`：三列内容卡片、完整桌面导航。
- `681–920px`：两列卡片、可滚动桌面导航。
- `<= 680px`：单列内容、固定底部五项主导航、弹窗改为底部抽屉。
- `<= 380px`：统计卡片改为两列，主统计占满首行。

## 组件规则

- `AppHeader` 是所有登录后页面的统一品牌、标题和导航入口。
- `.zone` 用于一组完整任务；`.item-card` 用于可扫描的数据或入口。
- 主按钮每个任务区最多一个；危险操作必须使用明确文字，不使用图标代替。
- 状态使用文字标签：正常、临期、过期、待确认；图形只可辅助，不可代替文本。
- 表单标签始终位于控件上方；错误紧邻任务区域显示，成功反馈使用绿色状态框。
- 对话消息区使用用户/小知两种气泡，不展示模型供应商或技术状态给普通用户。

## 验收清单

- 390×844、1440×900 无横向溢出。
- 移动端底部导航不遮挡最后一段内容。
- 弹窗可滚动，确认按钮在手机上始终可达。
- `prefers-reduced-motion` 下关闭非必要动画。
- 页面标题、表单标签、按钮均有可识别的无障碍名称。
